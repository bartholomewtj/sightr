# T27 — Diff panel: scope picker, changed-files tree, lazy per-file patches

Status: built and merged 2026-10-19 (PR #106; diffs series). Build-time amendments are recorded in this file. Depends on: T13 (right panel, Git tab), T24 (per-run changed-files summary and its tap-through), T25 (renderer decision, behind the `DiffCodeView` seam), T26 (bridge diff API). Plan: [`docs/T3_ADAPTATION.md`](../../T3_ADAPTATION.md). web2 only; read-only.

## Problem

Review is split across two weak places. The Git tab's "Changes" (`web2/src/components/right-panel/GitPanel.tsx`) shows the working tree against HEAD from one 256 KB response, with no scope choice, no tree and nothing for "what did this run change". Its branch view (`HistoryDiff`) is committed-only and lists files flat. T3 has one `DiffPanel` for all of it (`apps/web/src/components/DiffPanel.tsx` + `DiffPanelShell.tsx`, toggled by `diff.toggle`). Sightr's ledger records `skip` for `DiffPanel.tsx` and `DiffFileStatus.tsx` (`web2/t3-upstream.json`, `decisions`); the diffs series reverses both. This slice is the panel. The renderer is T25's choice, so the panel is written against the seam and never imports a diff library.

## Change

**Placement (decision): a new right-panel kind `diff`, not a fold into Git.** The Git tab is about history (commits, ahead/behind) and already carries 434 lines; the panel needs the whole sheet for a tree, a scope picker and long scrolling diffs, and keeps its own state. The Git tab links in; commits and history stay there. The cost is a fourth phone button and tab (checked live at 320 and 390 px; the sheet's tab strip scrolls sideways instead of clipping).

- `web2/src/rightPanelStore.ts`: `RIGHT_PANEL_KINDS` gains `"diff"` (appended, so saved `activeSurfaceId` values stay valid; `RIGHT_PANEL_LABEL` "Diff"). `RightPanelTabs.tsx`: `RIGHT_PANEL_ICON.diff` (lucide `DiffIcon`) and a `RightPanelSurface` branch. The phone header buttons (`_chat.thread.$threadId.tsx`, `PhonePanelButtons`) and the sheet strip (`RightPanelSheet.tsx`) already map over the kinds.
- Keybinding `diff.toggle`, `mod+d` (T3's key, kept on purpose: it stays identical for keybinding syncs; Bart's call, 18 Oct 2026), `when: "!terminalFocus"` (so ctrl+d still reaches an armed terminal), mirroring T3 `packages/shared/src/keybindings.ts`. The handler calls `preventDefault`; in a plain browser tab `mod+d` is the bookmark key, so there the browser may win. The installed PWA is the supported surface, and the palette action is the fallback. Edit `web2/src/t3/contracts/keybindings.ts` (`STATIC_KEYBINDING_COMMANDS`), `web2/src/t3/shared/keybindings.ts` (`DEFAULT_KEYBINDINGS`; fix its header, which says mod+d is not taken), `web2/src/keybindings.ts` (`COMMAND_LABEL`: "Open the Diff tab"), `GlobalShortcuts.tsx` (`registerShortcutHandler("diff.toggle", () => toggleRightPanelSurface("diff"))`) and an "Open Diff" action in `CommandPalette.tsx` beside "Open Terminal". `matchBinding` and the shortcuts sheet need no change.

**`web2/src/diffPanelStore.ts`** (pattern, T3 `apps/web/src/diffPanelStore.ts`): zustand `persist` with the safe-storage wrapper from `rightPanelStore.ts`, key `sightr:v2:diff-panel:v1`.
- `scopes: Record<threadId, DiffScope>`, newest 50 threads kept. `DiffScope = {kind:"workingTree"} | {kind:"branch", baseRef?: string} | {kind:"run", runId: string}`; `baseRef` absent means the bridge's default base (upstream, then `origin/HEAD`, `main`, `master`). Unknown or corrupt stored values fall back to `workingTree`.
- Not persisted: `reveal: {threadId, filePath, requestId} | null`. T3's `turn` variant carries `filePath` and `revealRequestId` itself; Sightr lifts them into `reveal` because the Git tab needs the same tap-through for the other two scopes. A new `requestId` on every call makes a second tap on the same file scroll again.
- `openDiff(threadId, scope, filePath?)` sets the scope, sets `reveal`, then calls `openRightPanelSurface("diff")` (desktop tab, or phone sheet), as `rightPanelStore.openFile` does. `openDiffForRun(threadId, runId, filePath?)` is what T24's card calls. The panel consumes a reveal once: it unfolds the file, scrolls its header into view and marks it with a short `motion-safe` highlight.

**`web2/src/components/DiffPanel.tsx`** (pattern, T3 `DiffPanel.tsx`) in `DiffPanelShell.tsx` (pattern, T3 `DiffPanelShell.tsx`: header slot, body, loading/empty/error frame). New files under `web2/src/components/diffs/`:
- `DiffScopePicker.tsx`, `DiffBranchPicker.tsx`: desktop is a Base UI `ui/menu.tsx` dropdown; phone is a `ui/sheet.tsx` bottom sheet with 44 px rows, and the branch sheet has a filter box. Items: "Working tree", "Branch vs {base}" and the base picker (names from T26's branch list), and "Run" with the thread's runs that have changes, newest first ("Run 7 · 3 files · 12m ago"). A stored `baseRef` missing from the list falls back to the default base with a one-line note.
- `diffFileTree.logic.ts`, `diffFileActions.ts` (adapted from T3 `apps/web/src/components/diffs/`, first-line header naming path and commit; Pierre types replaced by local ones). `DiffFileTree.tsx` (pattern, T3 `diffs/DiffFileTree.tsx`): our own `role="tree"` over that logic, single-child folders compressed, +N/-M per file and per folder, status chip, 44 px rows on `pointer-coarse`. `@pierre/trees` (beta) is not taken.
- `DiffFileStatus.tsx` (pattern, T3 `diffs/DiffFileStatus.tsx`): a visible letter chip (A, M, D, R, ?) with the word for screen readers; no hover tooltip, since the phone has no hover.
- `useDiffFilePatches.ts` (pattern, T3 `useReviewFilePatches.ts`, cap from `client-runtime/state/review.ts`): plain `fetch` to T26 through `web2/src/lib/diffApi.ts` (`fetchDiffSummary`, `fetchDiffFilePatch`, `fetchDiffBranches`; shapes are T26's, typed from `shared/`), no Effect. A queue with `PATCH_CONCURRENCY = 4`; a file is queued when unfolded or when its header nears the viewport (IntersectionObserver, 400 px margin), unfolded and revealed files first. Per-file state `idle | loading | ready | error | truncated | binary`, each with its own message: error has a Retry button, truncated says what was cut and offers Open in Files, binary shows "binary" and no patch. Scope change or unmount aborts every in-flight request.
- Refresh: the summary request sends the last `diffHash` as `If-None-Match`; a 304 changes nothing. A new hash keeps the old patches on screen and refetches only unfolded and near-viewport files (stale-while-revalidate, no flash). Triggers are the Git tab's, moved out of `GitPanel.tsx` into `right-panel/useRefreshTriggers.ts` (`useRunEnded`, visibility, `online`) and shared by both panels; the Refresh button too. Run scope needs no fetch: it follows the thread stream.
- Run scope reads `useRunScopeFiles(threadId, runId)` in `diffs/runScope.ts`, today a thin adapter over T24's per-run summary (journal `file_change` items grouped by path; `diffStr`, `truncated`, `errorText`). Several edits to one file show as consecutive hunks, "3 edits". A caption says it comes from the agent's edits and may not match the disk. T31 swaps the adapter's source for checkpoints and changes nothing else.
- Toolbar: scope picker, Wrap (`useDiffWrap`, per device, on by default below desktop), Collapse all (folds files, keeps patches), Refresh. Files render as `DiffCodeView` (T25) with only `path`, `patch`, `wrap`; this slice never reads its internals. Unfolded by default: the revealed file, else all files when there are 3 or fewer.
- Phone (< 1024 px), inside `RightPanelSheet`: one column. A header "Files · 12 · +230 −41" folds the tree open and shut (open on first visit, folded once a file is picked); picking a file unfolds it and scrolls to it. File headers are sticky with the path wrapping (clamped to 3 lines, full path on Copy path), Copy path and Open in Files, all 44 px. Back: the sheet is one history entry; the scope and branch sheets are a second. `useSheetHistory` in `RightPanelSheet.tsx` is changed so only the topmost open instance answers `popstate` (a module stack), so Back closes the picker, then the panel. Folding the tree, expanding a file and a reveal add no history entries. Content unmounts with the sheet; per-thread-and-scope fold state lives in a module map (as `navMemory` in `GitPanel.tsx`) and scroll in `useScrollMemory` (`diff:${threadId}:${scopeKey}`).
- Desktop: when the panel itself is at least 600 px wide (ResizeObserver on the panel, not the viewport; the default 420 px is narrower) the tree is a left column and diffs a right one; narrower, it is the phone's collapsible header. Selecting a tree row scrolls and unfolds.

**Git tab: "Changes" becomes a link (decided with Bart, 18 Oct 2026).** The working-tree list and its inline per-file expansion leave `GitPanel.tsx`; one working-tree diff lives in the Diff panel. ## Invariants

- Read-only. The panel makes no request while unmounted, and none for a file that is folded and off-screen. At most 4 patch requests are ever in flight.
- web2 never branches on a harness id. The client sees repo-relative paths only, as in the Git tab.
- A phone path exists for every desktop interaction (picker, tree, reveal, wrap). Targets are 44 px on `pointer-coarse`; paths wrap and are never truncated outright.
- Back closes the topmost sheet only and never leaves the thread while one is open.
- The panel names no renderer: swapping T25's `DiffCodeView` changes no file in this slice.
- Run scope never claims exactness. A truncated or errored journal diff says so.
