## Standing rules

- Windows only. Bun is the runtime. Herdr method names stay in `bridge/herdr-client.ts`.
- One spec per run. Do not implement a sibling spec in the same run. Do not implement row 4 from `docs/specs/`.
- Brand assets stay in `/brand/` (gitignored). Do not force-add them.
- Product briefs and slice specs do not edit this file or `DECISIONS.md`.
- **STATE.md tidy:** rewrite the whole file at session end; never append. Only *now* and at most three *next* actions. Missing is fine. **DECISIONS.md:** ask first; cap 15 / ~40 lines.
- No `NEXT-SESSION.md`, no `ROADMAP.md`.
